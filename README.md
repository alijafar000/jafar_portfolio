## 📖 About The Project

This is my personal portfolio website that serves as an online resume and showcase of my work. Built with HTML, CSS, and JavaScript, it features a clean, modern design with smooth animations and responsive layout that works seamlessly across all devices.

### Key Highlights:
- Fully responsive design
- Smooth scrolling navigation
- Dynamic typing animation
- Interactive project cards with hover effects
- Contact form integration with Web3Forms
- Mobile-friendly hamburger menu

## ✨ Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Smooth Scrolling**: Seamless navigation between sections
- **Typed.js Animation**: Dynamic text rotation in hero section
- **Project Gallery**: Interactive project cards with live preview links
- **Skills Section**: Visual representation of technical competencies
- **Education Timeline**: Academic background display
- **Contact Form**: Functional contact form with Web3Forms API
- **Social Links**: Integrated social media profiles
- **Sticky Navigation**: Persistent header for easy navigation

## 🛠 Technologies Used

### Frontend
- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling, animations, and responsive design
- **JavaScript** - Interactive features and DOM manipulation
- **Typed.js** - Dynamic typing animation library

### Icons & Fonts
- **Font Awesome 6.4.0** - Icon library
- **Google Fonts** - Poppins, Montserrat, Kanchenjunga fonts

### Form Handling
- **Web3Forms** - Contact form backend service
